## Recommender (M2.3 fallback → P6 market/fit composite + P2 reason bits)

- `ball_buddy/domain/scorer.py` (P6, new) — the composite pool scorer, pure/Qt-free, ported from autodraft's `engine/scoring.py::ValueGapScorer` onto canonical `players.csv` rows (dicts). `score_pool(rows, my_rows, overall, team_count, top_n=10) -> list[recommend.Suggestion]` (reuses the existing `Suggestion`; raw split numbers live in the reason string so the board panel is untouched). **Formula:** score = `MARKET_WEIGHT × market + FIT_WEIGHT × fit_norm + tag_adj`, with `market = (rank_max − rank)/rank_max` (no rank → 0.0, `rank=None`), `fit_norm` = min-max of the weighted signed-z fit over candidates (all-equal → 0.5). Fit per candidate = Σ_cat `WEIGHTS[cat] × z[cat] × mult[cat]`; per-cat `edge` = my roster mean signed z − pool mean signed z, `edge < 0` → hole ×`HOLE_MULT` (1.25), `edge >= COVERED_THRESHOLD` (0.5) → covered ×`COVERED_MULT` (0.75), else ×1. **Empty my roster → edge = −pool mean per cat** (autodraft's synthetic −1.0 hole-everywhere rejected — the pool baseline is the honest start). z columns via `importer.Z_FIELD_FOR`; **`z_to` is negated at parse** (source z_to correlates +0.999 with raw to_pg — not sign-corrected, so positive raw z_to = high TO = *bad*; after the flip, higher signed z is better in every cat). `WEIGHTS` = one entry per `engine.CATS` key, all 1.0 (module constant, not settings — autodraft league.json precedent). **Tag:** `adp < REACH_FACTOR(0.8) × overall` → REACH (−`TAG_ADJUSTMENT` 0.10 — market ahead of us), `adp > VALUE_FACTOR(1.25) × overall` → VALUE (+0.10), else "on board" (0), blank adp → "no ADP" (0). **Value-gap flag** (reason only, never the score): ≥`VALUE_GAP_MIN_CANDIDATES` (10) candidates, rank in top `VALUE_GAP_TOP_FRACTION` (0.10) of the pool, ADP > (decile floor ADP — the ADP of the worst-ranked decile player carrying an ADP) + `VALUE_GAP_DEFAULT_ROUNDS` (2) × `team_count` rounds → "value gap: rank R, ADP A — market oversleeping". All 11 constants module-level (draft-day tunables). **Tolerance (laxer than autodraft, which raises):** blank z cell → 0.0 for that cat; blank `adp_round` → None ("no ADP" tag, excluded from the gap flag); blank/unparseable rank → market 0; blank name → skipped. Sort: score desc, then rank asc (unranked last), then row order.
- `ball_buddy/domain/recommend.py` — two entry points, both pure/Qt-free:
  - `recommend` (M2.3, verbatim): per-pick top-N by `rank` asc (ties by `value` desc); unranked rows sort last and carry `rank=None` → UI "—" (no invented numbers).
  - `recommend_need_aware(rows, excluded, teams, my_team, top_n=5, overall=0, team_count=0)` (P6): the **ordering** is `scorer.score_pool` on the non-excluded candidates with `my_rows = teams[my_team]` (P2's `NEED_WEIGHT`/`SCARCITY_WEIGHT` score line and constants are **deleted** — fill/scarcity no longer score). The P2 bits are **appended to each reason** (never scored): (a) top-2 **category gaps** the candidate fills — per H2H CATEGORY (9 cats via `engine.CATS`), team/candidate projections reuse `engine.project_roster` / `engine.project_player` (same engine as matchups, so pool bias cancels); per cat `gap_c` = how far MY team sits below the league-median team in the better direction (`engine.DIRECTIONS` — `to` is lower-is-better), ÷ league spread (max−min across teams; 0 → 1), candidate fill `f_c` = candidate season value ÷ spread (for `to`: `1 − value/spread`), per-cat filled = `max(0, min(g_c, f_c))` (clamped [0, 1]); known limitation unchanged: empty teams project to zeros and inflate spreads (diluted pre-draft, recovers as picks are entered); and (b) the C1 scarcity bit (median remaining pool count across positions − remaining at the candidate's primary position; facts, not prediction). `teams` maps every team → pool rows of its SECURED players (draft picks + active keepers — all count, no starter/bench); `my_team` = `settings["my_team"]`; `overall` (1-based snake index) + `team_count` (start-order length) feed the scorer's tag boundaries / gap threshold (board passes both; 0 = no draft context). Efficiency: each team's secured rows projected once per call; each candidate projected once (cached by name) for the fill bits. Each `Suggestion` reason is " · ".join: `mkt {rank}/{rank_max} → {market:.2f}` (or `mkt unrated`) · `fit {fit:+.2f}z: holes A, B; covered C` · tag bit (`REACH: ADP x.x vs pick N` / `VALUE: …` / `ADP x.x on board` / `no ADP`) · optional `value gap: …` · optional `fills … gaps` · optional C1 bit. **Fallback (unchanged):** no teams / blank or unknown my-team → the M2.3 ranking with a reason ("pool rank N" / "unranked (top pool order)") instead of crashing. `category_gaps` / `cat_fill` stay exported (P2 fill bits + `relative.py` both use them).
  - Exclusions identical in both modes: drafted picks + active keepers (caller-computed in `board.py::_excluded_names`); **opted-out keepers stay draftable/suggestable** (their pick isn't forfeited).
- Suggestion panel in `board.py` updates per current pick; alias bridging both sides. `DraftBoard._team_projections` builds the per-team secured rows from entered picks (bridged) + active keepers — exactly the dict[team → secured pool rows] the recommender wants; the panel has 5 columns (Player, Pos, Value, Rank, **Reason**) and calls `recommend_need_aware` with `settings["my_team"]` + `overall=current_pick.overall` + `team_count=len(start_order)` (call-site only, no P7 UI).

## Relative panel (P3)

`ball_buddy/domain/relative.py` — per-category **BUILD/COAST/PUNT** tags for my team vs the league, independent of the recommender ("invest in / ignore / abandon" vs "who fills my gap now"). Pure/Qt-free; reuses the promoted `recommend.category_gaps` + `recommend.cat_fill` (formerly `_category_gaps` / `_cat_fill` — the underscore dropped so P3 shares the exact median/spread/direction math and its zero-inflation caveat; `__all__` extended, no external code referenced the privates). `category_tags(teams, my_team, pool_rows, excluded, top_n=3, bottom_n=3, punt_close=0.25)` → `list[CatTag] | None` (`None` on empty teams / blank-or-unknown my-team — same fallback semantics as `recommend_need_aware`; the panel hides). Per cat: rank = 1-based position across teams sorted best-first by `engine.DIRECTIONS` (ties: team name asc — deterministic); signed `gap` (positive = behind, better direction); `gap_norm = max(0, gap)/spread`; `best_fill_norm` = max `cat_fill` over non-excluded pool (0.0 if none). Tag rules: **raw league spread 0 (all teams equal — pre-draft) → COAST** (no signal; absorbs the zero-inflation caveat — tags are only meaningful once picks exist); `rank <= top_n` → BUILD; `rank >= n − bottom_n + 1` AND `best_fill_norm < punt_close × gap_norm` → PUNT (bottom and the remaining pool can't close ~25% of the gap); else COAST. `top_n` / `bottom_n` / `punt_close` are keyword defaults, documented as draft-day tunables.

`board.py` — `relative_panel` (mirrors the suggest panel: `#panel` widget + `#title` + 9×5 `QTableWidget`, Cat/Mine/Median/Gap/Tag, NoSelection, stretch header, maxHeight 300, initially hidden) as a sibling below the suggest panel in `inner`; `render()` calls `_render_relative(report)` after `_render_suggestions(report)`; the no-snapshot early return in `refresh()` hides it. Rows use `CAT_LABELS` (imported from `ui/views/matchup`); count cats `f"{v:.1f}"`, pct cats `f"{v:.4f}"`, signed gap `f"{g:+.1f}"` / `f"{g:+.4f}"`; v1 tags are monochrome text (coloring deferred).

Tests: `tests/domain/test_relative.py` (12 teams × 1 player, FIELDNAMES stat rows: top-pts → BUILD + flat cats COAST, bottom + zero-reb pool → PUNT, bottom + pool closing >25% → COAST, middle rank → COAST, `to` direction both ways (lowest TO → BUILD, highest TO + weak pool → PUNT), fallbacks → `None`, all-zero teams → all COAST, exact punt-close boundary (fill == 0.25×gap → COAST, just under → PUNT), excluded pool rows ignored for fill); `tests/ui/test_board.py` (`make_manual_service_12` helper — 12 manual teams + `my_team="Alpha"`; keeper-per-team pool where Alpha is best at pts and worst at reb + weak filler → panel visible, 9 rows, pts BUILD / reb PUNT; blank `my_team` → panel hidden).
